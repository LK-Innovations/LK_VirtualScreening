# A virtual screening platform by LK Innovations 

A virtual screening platform for small molecule discovery mentioned in the manuscript 

## **AI-enabled discovery of small molecules targeting complementary pathways for hair follicle rejuvenation**

The Extrinsic directory contains the virtual screening workflow for the extrinsic pathways mentioned in the manuscript

The Intrinsic directory contains the virtual screening codes for the intrinsic pathway mentioned in the manuscript

The details, including installation guide, example demostration, workflow usage, are described by README files in each separate folder.
